# 🏰 像素塔防 Pixel Tower Defense
一个**单文件、零依赖**的像素风塔防小游戏，用纯 HTML + JavaScript + Canvas 实现。
双击 `index.html` 即可在浏览器中开玩，无需安装任何环境、无需联网、无需构建工具。
> 适合作为前端入门 / 开源练手项目，代码结构清晰、注释完整，方便二次修改。
---
## 🎮 项目简介
敌人会从左侧 **3 条路线** 出发，沿着路径冲向右侧的基地。
你需要在路径旁的草地上建造防御塔，拦截并消灭它们。
漏掉一个敌人会扣除生命值，**生命归零即失败**；成功守住全部 **10 波** 进攻即为**胜利**。
---
## 🕹️ 玩法说明
### 基本流程
1. 点击 **「▶ 开始游戏」** 进入战斗。
2. 点击下方 **防御塔卡片** 选中塔型。
3. 点击地图上的 **绿色草地格子** 建造防御塔（路径和障碍格不能建造）。
4. 敌人被击杀会掉落金币，用金币继续建塔或升级。
5. 清空一波后会有金币奖励，点击 **「⏩ 提前召唤下一波」** 可加速节奏。
### 操作方式
| 操作 | 说明 |
|------|------|
| 鼠标左键 | 选择塔 / 建造 / 选中已有塔 |
| `1` ~ `4` | 快速选择对应防御塔 |
| `空格` | 暂停 / 继续游戏 |
| `U` | 升级当前选中的塔 |
| `X` | 出售当前选中的塔（返还 60% 金币） |
| `Esc` | 取消当前选择 |
### 防御塔一览
| 塔型 | 造价 | 特点 | 基础伤害 | 射速 | 射程 |
|------|------|------|----------|------|------|
| 🏹 箭塔 | 50 | 射速快，单体输出 | 9 | 0.42s | 2.4 格 |
| 💣 炮塔 | 90 | 范围溅射，攻速慢 | 22 | 1.15s | 2.1 格 |
| ❄️ 冰塔 | 70 | 减速敌人，伤害低 | 5 | 0.70s | 2.2 格 |
| 🔫 激光塔 | 130 | 高伤，直线穿透多个敌人 | 16 | 0.95s | 3.0 格 |
> 所有防御塔均可升级，最高 **5 级**。每级提升约 **42% 攻击力** 和 **10% 射程**。
### 敌人一览
| 敌人 | 血量 | 速度 | 护甲 | 赏金 | 特点 |
|------|------|------|------|------|------|
| 🟢 史莱姆 | 42 | 中 | 0 | 8 | 最常见的杂兵 |
| 🟣 蝙蝠 | 30 | 快 | 0 | 7 | 血少但跑得飞快 |
| ⚪ 石魔 | 150 | 慢 | 3 | 18 | 高血量高护甲 |
| 🔴 BOSS | 620 | 慢 | 6 | 120 | 第 10 波登场，漏掉扣 5 点生命 |
> 敌人血量会随波次提升（每波约 +13%），越到后期越难缠。

## 🚀 运行方式
### 方式一：直接双击（推荐）
下载或克隆本项目后，**双击 `index.html`**，浏览器会自动打开游戏页面，立即开玩。
### 方式二：本地服务器（可选）
如果你希望用 `http://` 方式访问：
```bash
# Python 3
python -m http.server 8000
# 或 Node.js
npx serve .
```
然后浏览器访问 `http://localhost:8000`。
### 兼容性
支持所有现代浏览器：Chrome / Edge / Firefox / Safari（含移动端浏览器）。

## ✨ 功能特性
- 🗺️ **3 条独立行进路线**，需要分兵布防，策略性更强
- 🏹 **4 种防御塔**：单体、溅射、减速、穿透，属性各异
- 👾 **4 种敌人**：血量、速度、护甲、赏金各不相同
- ⬆️ **升级系统**：防御塔可升至 5 级，攻击力与射程同步提升
- 💰 **出售系统**：可拆除已建塔，返还 60% 投入金币
- 🌊 **10 波敌人**：难度逐波递增，含 BOSS 波，有明确胜负判定
- ⏩ **变速与暂停**：支持 1x / 2x / 3x 加速和空格暂停
- 🎨 **纯像素风渲染**：全部图形由 Canvas 绘制，无任何图片素材
- 📦 **单文件零依赖**：一个 HTML 文件搞定，方便分享与部署

## 🛠️ 技术说明
| 项目 | 说明 |
|------|------|
| 技术栈 | 原生 HTML + CSS + JavaScript (ES6) |
| 渲染方式 | HTML5 Canvas 2D，`image-rendering: pixelated` 保持像素锐利 |
| 依赖 | **无**，不需要任何第三方库或构建工具 |
| 文件结构 | 单文件 `index.html`，内嵌全部 CSS 与 JS |
| 游戏循环 | `requestAnimationFrame` + 时间差（delta time）驱动 |
| 地图系统 | 16 × 9 的格子地图，格子类型：草地 / 路径 / 障碍 |
| 寻路方式 | 预定义折线路径，敌人按累计行进距离取坐标 |
| 碰撞检测 | 圆形范围判定 + 子弹追踪 + 激光直线投影判定 |
| 代码规模 | 约 900 行，注释完整，便于阅读和二次开发 |
### 核心模块
```
index.html
├── 配置层     CELL / COLS / ROWS / ROUTES_DEF / TOWER_TYPES / ENEMY_TYPES / WAVES
├── 状态层     game 对象（金币、生命、波次、塔、敌人、子弹、特效）
├── 逻辑层     波次生成 / 敌人移动 / 塔攻击 / 子弹命中 / 伤害结算
├── 渲染层     render() 绘制地图、塔、敌人、子弹、特效、UI 遮罩
└── 交互层     鼠标点击建造 / 键盘快捷键 / 按钮控制
```
### 想自己改数值？
直接编辑 `index.html` 顶部的配置常量即可，无需改动逻辑代码：
- `TOWER_TYPES` —— 调整塔的造价、伤害、射程、攻速
- `ENEMY_TYPES` —— 调整敌人的血量、速度、护甲、赏金
- `WAVES` —— 调整每一波的敌人组合与数量
- `ROUTES_DEF` —— 修改敌人行进路线
